# So funktioniert diese Vorlage

- Jede Folie hat eine Überschrift und kurzen Text
- Pro Folie ein Gedanke, dann bleibt alles gut lesbar
- Klicke auf einen Text, um ihn zu ändern
- Über "Neue Folie" wählst du eine passende Anordnung
- Bilder ziehst du einfach auf die Folie
- Mit der Taste F5 startest du den Vortrag

# Text und Bild

- Ein gutes Bild sagt mehr als ein Absatz
- Querformat und Hochformat funktionieren
